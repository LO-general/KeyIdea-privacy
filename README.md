# Privacy Policy & Terms of Use – KeyIdea

Last updated: 04/05/2026

## 1. Overview

KeyIdea is a browser extension designed to help users save, organize, and review selected text from web pages.

The extension allows users to store selected ideas locally in their browser, organize them into folders and themes, and review them later.

## 2. Data Collection

KeyIdea does not collect, store, sell, share, or transmit any personal data to external servers.

The extension does not use analytics, tracking tools, advertising trackers, cookies, or third-party monitoring services.

## 3. Local Storage Only

All saved content, including ideas, folders, themes, dates, and review information, is stored locally in the user's browser using browser storage.

This data remains on the user's device and is not accessible by the developer.

## 4. User Responsibility

The user is solely responsible for the content they choose to save using KeyIdea.

Users should not save sensitive, confidential, private, illegal, copyrighted, or personal information unless they have the legal right to do so.

KeyIdea is only a local organization tool and does not verify the legality, accuracy, ownership, or confidentiality of the content saved by the user.

## 5. No Guarantee

KeyIdea is provided "as is" without warranties of any kind.

The developer does not guarantee that the extension will be error-free, uninterrupted, compatible with all websites, or permanently available.

The developer is not responsible for data loss, browser errors, user misuse, saved content, or any direct or indirect damage resulting from the use of the extension.

## 6. Data Deletion

Users can delete saved content directly inside the extension.

Users may also remove all locally stored data by uninstalling the extension or clearing browser extension storage.

## 7. No External Accounts

KeyIdea does not require user registration, login credentials, payment credentials, or external accounts to function.

## 8. Changes to This Policy

This policy may be updated if the extension evolves.

If future versions include cloud synchronization, user accounts, analytics, or external servers, this policy will be updated accordingly.
